1. QUÉ ES ESTE PROYECTO
================================================================================

Web profesional para 24Shoots Media (@24shootsmedia en Instagram).
Productora audiovisual y agencia de contenido en Valencia.
Eslogan: "DOMINA EL IMPACTO"
Logo: fondo negro, texto blanco, acento naranja.

Objetivos de la web:
  - Impacto visual (estética cinematográfica / premium)
  - Generar leads y ventas (formulario + WhatsApp)
  - SEO local (Valencia, servicios audiovisuales)
  - Fácil de mantener y REUTILIZABLE para futuras webs de clientes
  - Español + inglés
  - Funciona en móvil, tablet y escritorio
  - Stack mayormente GRATUITO (Vercel, JSON, sin CMS de pago)

8. PASOS PARA CONTINUAR EN CASA (ORDEN EXACTO)
================================================================================

PASO 1 — Llevar el proyecto al PC de casa
  - Copiar toda la carpeta 24shoots (USB, OneDrive, Google Drive, zip)
  - Incluir: código + CUESTIONARIO + este CONTINUAR-EN-CASA.txt
  - El logo original: 470950536_484370707661416_6724443183514597849_n.jpg
    (también copiado como public/logo.jpg)

PASO 2 — Instalar Node.js en casa
  - Descargar LTS: https://nodejs.org/
  - Verificar en terminal: node -v  y  npm -v

PASO 3 — Instalar dependencias y arrancar
  cd ruta/a/24shoots
  npm install
  npm run dev
  Abrir: http://localhost:3000  (redirige a /es)

PASO 4 — Enviar cuestionario al cliente
  - Archivo: CUESTIONARIO-CLIENTE-24SHOOTS.txt
  - Pedir mínimo: logo HD, WhatsApp, email, legal, 6-9 proyectos portfolio

PASO 5 — Integrar respuestas del cliente
  - config/site.json → contacto, legal, url
  - content/*/portfolio.json → proyectos reales
  - content/*/pages.json → textos personalizados si los envían
  - public/logo.jpg → logo HD

PASO 6 — Probar en dispositivos
  - Chrome, Safari, móvil (responsive)
  - Formulario de contacto
  - Botón WhatsApp
  - Cambio ES/EN

PASO 7 — Deploy en Vercel (gratis)
  - Subir a GitHub (repo privado o público)
  - vercel.com → Import project → conectar repo
  - URL: 24shoots.vercel.app (o similar)
  - Actualizar config/site.json con la URL real de Vercel

PASO 8 — Cuando tengan dominio
  - Vercel → Settings → Domains → añadir dominio
  - En el registrador del dominio: apuntar DNS a Vercel (CNAME o A)
  - Actualizar config/site.json → "url": "https://tudominio.com"
  - Redeploy

PASO 9 — Producción formulario email
  - Crear cuenta Resend (gratis): https://resend.com
  - API key en .env.local: RESEND_API_KEY=...
  - Actualizar src/app/api/contact/route.ts para enviar email

PASO 10 — Fase 2 según respuestas del cliente
