QUIÉN SOY
---------
- Científico de datos con perfil técnico.
- Desarrollador web en formación/práctica (Next.js, TypeScript, Tailwind).
- Quiero vender servicios digitales y construir producto propio reutilizable.
- Trabajo desde España. Objetivo: clientes locales + remoto.


QUÉ QUIERO VENDER
-----------------
1) WEBS ORIENTADAS A CONVERSIÓN
   - Para pymes, autónomos, creadores, agencias pequeñas
   - Enfoque: útil, rápida, SEO base, móvil primero, fácil de mantener

2) AUTOMATIZACIONES
   - Captura de leads (formulario → email/CRM)
   - Brief automático para clientes
   - Presupuestos orientativos por reglas
   - Reporting mensual (community, web, campañas)
   - Flujos Make/Zapier o propios según escale

3) HERRAMIENTAS PROPIAS (FUTURO)
   - CRM leads ligero
   - Motor de presupuestos
   - Panel de seguimiento de proyectos
   - Plantilla clonable para nuevos clientes (npm run new-site)


DIFERENCIAL
-----------
- No solo "hago webs bonitas": webs que venden + automatización operativa.
- Base reutilizable: entrego más rápido que agencia tradicional.
- Mantenimiento.
- Perfil híbrido data + dev: puedo medir y optimizar con datos.


CLIENTE IDEAL
-------------
- Negocio local o digital que necesita presencia web seria YA.
- Tiene Instagram pero web floja o inexistente.
- Quiere leads (WhatsApp, formulario), no solo "tarjeta de visita".
- Presupuesto limitado pero valora calidad y claridad.
- Ejemplos: productoras, restaurantes, clínicas, inmobiliarias, coaches.


LO QUE NO QUIERO (AL INICIO)
----------------------------
- WordPress pesado para todo.
- Depender de CMS de pago para cada cliente.
- Prometer SEO milagroso en 1 semana.
- Construir app móvil nativa.
- Automatizaciones complejas antes de tener 3 clientes reales.


STACK PREFERIDO
---------------
- Frontend: Next.js 15 + Tailwind + TypeScript
- Contenido: JSON (config/site.json, content/es, content/en)
- Hosting: Vercel (gratis al inicio)
- Repo: GitHub
- Email: Resend (gratis hasta 3000/mes)
- DB futura: PostgreSQL (Supabase/Neon free tier)
- Jobs: cron + API routes o worker simple
